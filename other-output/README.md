## 알려진 제약

- 중국어 음성은 설치된 로컬 한국어 모델에서 오인될 수 있다. 최종 중국어 표현은 화면·PDF·DOCX에서 확인된 표기만 채택했다.
- 3강은 640×360 원본이라 작은 판서 OCR 확신이 상대적으로 낮다.
- DOCX는 Word 메타데이터 3페이지지만 전체 페이지 시각 렌더는 환경 제약으로 확인하지 못했다. 전체 OOXML 텍스트·서식 추출은 완료했다.
- 중복 제거 기준 저신뢰 토큰 2,014개와 5초 이상 무인식 후보 480구간은 전사에 그대로 보존했다.
