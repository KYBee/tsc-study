# TSC 시험직전 체크리스트

## 시험 구조

- [ ] Part 1~7의 문항 수와 준비·답변 시간을 확인했다. [01강 / P01 / 3페이지]
- [ ] Part 2·3 화면에는 질문 한자가 없고 Part 4·5에는 질문 한자가 보인다는 차이를 안다.

## Part 1·2

- [ ] 자기소개 네 답이 바로 나온다.
- [ ] 그림의 시간·수량·위치를 먼저 본다.
- [ ] `比…更…`와 `没有…`를 구분한다.
- [ ] `很更`, `比…很…`을 쓰지 않는다.
- [ ] 질문과 그림이 다르면 `不是` 후 실제 동작을 말한다.

## Part 3

- [ ] 감사·부탁·초대·축하·곤란을 듣고 구분한다.
- [ ] `当然可以/没问题/不好意思/恭喜你`가 즉시 나온다.
- [ ] 특정 명사를 놓쳐도 발화 기능이 확실하면 첫 반응을 한다.
- [ ] 너무 길게 Part 4처럼 말하지 않는다.

## Part 4

- [ ] 15초에 직답·이유·사례·정리를 잡는다.
- [ ] 25초 동안 정확한 네 문장 이상 수준으로 말한다.
- [ ] 성격·운동·요리·월급·계절·회사·분실·여행 주제를 말해 봤다.
- [ ] 질문 한자의 핵심 뜻을 확인한다.
- [ ] 확실하지 않은 고급어를 쉬운 말로 바꿨다.

## Part 5

- [ ] 30초에 입장과 근거 순서를 잡는다.
- [ ] `有利有弊` 장단점 구조 또는 `第一/第二/第三` 대책 구조를 쓸 수 있다.
- [ ] 50초가 길어도 문제 문장만 반복하지 않는다.
- [ ] `越来越很…` 같은 정도 중복을 피한다.

## 발음·감점

- [ ] 성조가 불확실한 단어를 표시하고 녹음했다.
- [ ] 전치사·어순·수량 오류를 오답노트로 확인했다.
- [ ] 축하·소식의 당사자를 반대로 듣지 않는다.
- [ ] 마지막 약 5초에는 확실한 문장만 추가한다. [04강 / V04c / 00:46:27-00:47:24]
- [ ] 많이 말하는 것보다 정확한 문장을 우선한다.
