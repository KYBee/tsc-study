# TSC 문제유형별 답변템플릿

> 아래는 강사가 실제 화면·문서에서 제시한 구조만 재배열한 것이다. 새로운 만능 문장을 만들지 않았다.

## Part 1 고정 답

1. 이름: `我叫XX。`
2. 생년월일: `我生于XX年XX月XX号。`
3. 가족: `我家有XX口人。`
4. 소속: `我在XX工作。`

출처: [01강 / P01 / 5페이지]. 짧게 답하고 발음을 정확히 한다.

## Part 2 그림 답

### 비교

- 긍정: `A比B更+형용사。`
- 반대: `A没有B+형용사。`
- 금지: `A比B很+형용사`, `很更`.

### 위치·존재

- `주어+在+장소/방위사。`
- `장소+有+대상。`

### 질문과 그림이 다를 때

- `不是，+그림의 실제 동작。`
- 실제 예: `不是，她在跳舞。` [07강 / V07 / 00:00:22]

### 실행 순서

1. 3초 동안 그림의 대상·관계·수량을 본다.
2. 의문사 자리에 그림 정보를 넣는다.
3. 6초 동안 한 문장만 정확히 말한다.

## Part 3 대화 완성

### 부탁 수락

`当然可以。/ 没问题。` → 할 행동 한 문장.

### 정중한 거절

`不好意思。` → 지금 상황/이유 → `请等一下/下次吧` 계열 대안.

### 좋은 소식

`是吗？` → `恭喜你！` → 식사·만남 등 후속 한 문장.

### 상대가 힘들 때

상황 확인 → 공감 → 자료에 나온 쉬운 휴식/도움 제안.

### 규칙

- 화면 한자를 기대하지 않는다.
- 특정 명사를 놓쳐도 발화 기능이 확실하면 첫 반응을 말한다.
- 15초를 억지로 긴 설명으로 채우지 않는다.

## Part 4 STEP 구조

06강 화면의 실제 구조는 다음과 같다. [06강 / V06 / 00:22:31-00:22:38]

1. STEP1: 질문에 직접 답한다.
2. STEP2: 이유, 세부, 개인 경험 또는 효과를 붙인다.
3. STEP3: `总之` 계열로 정리한다.

### 인물·상사

- STEP1: 어떤 사람인지 한 특징.
- STEP2: 업무/생활에서 도운 구체 행동 + 다른 특징.
- STEP3: 사람들이 좋아한다/환영받는다는 화면 결론.

### 생활·취미·운동

- STEP1: 장소/빈도/선호 직답.
- STEP2: 접근성·날씨·건강·기분 등 강의에서 사용한 이유.
- STEP3: 내 선택을 다시 정리.

### 요리·외국어·월급

- STEP1: 좋아하는지/기회가 많은지/누가 관리하는지.
- STEP2: 대표 요리·회사 상황·생활비/저축/투자.
- STEP3: 절약·건강·개인 결론.

### 경험·잃어버린 물건

- 언제/어디서 잃었는지 → `我感到特别可惜。` → 선물/의미 → 앞으로 주의.
- 출처: [06강 / V06 / 01:00:04-01:02:14]

### 선택·비교

- 하나를 먼저 고른다 → 반대 선택의 불편/내 선택의 장점 → 개인 성향/경험 → 결론.
- 예: 단체여행 대 자유여행. [07강 / V07 / 00:10:21-00:12:04]

## Part 5 의견 구조

### 장단점

`我觉得有利有弊。` → 장점(도움·관심) → 단점/조건(비용 등) → 내 결론.

출처: [05강 / D05 / -5P-]

### 선택 의견

가격/스타일 중 하나 → 월급·생활비 또는 유행·광고 → 구체 예 → 입장 재확인.

### 사회 문제 대책

`第一…` 개인 의식/능력 → `第二…` 학교·사회 교육 → `第三…` 제재 → `以上是我的想法。`

출처: [06강 / V06 / 01:12:50-01:15:16]

## Part 7

자료에서 확인된 것은 그림 순서와 마지막 반전을 놓치지 말라는 점뿐이다. 완전한 90초 문장 템플릿은 강의에서 제시되지 않아 만들지 않는다. [05강 / V05 / 01:12:15-01:12:31]
