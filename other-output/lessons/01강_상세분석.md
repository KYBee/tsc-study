| 주어+在+장소 / 장소+有+대상 | 위치와 존재를 구분 | 公司附近有很多餐厅。 | 주체·장소를 뒤섞지 않음 | 그림 정보 직접 답 | [01강 / P01 / 7, 12페이지] |
| 시점 앞·기간 뒤 | 시점은 앞, 동작 기간은 동사 뒤 | 我工作10年了。 | 我10年工作了。 | 어순 오류 방지 | [01강 / P01 / 11페이지] |
| 의문사 자리 치환 | 질문의 什么/谁/哪儿/几 자리에 그림 답을 넣음 | 我是坐地铁来的。 | 의문사가 있으면 `吗`를 더하지 않음 | 6초 안에 구조 재사용 | [01강 / P01 / 11페이지] |

## 11. 발음과 성조

- 발음·딕션·성조는 시험 결과에서 매우 중요하다고 반복했다. 수업 중 교정 시점을 녹화로 되돌려 확인한다. [01강 / V01a / 00:11:00-00:12:12]
- PDF의 발음 주의 문장에는 `我最近很忙，你呢？`, `你做菜做得真棒！`, `我今天有点儿不舒服。` 등이 병음과 함께 제시됐다. [01강 / P01 / 9페이지]
- 비교문 `比`의 성조와 `更` 사용을 함께 연습했고, 긴장해서 `很`을 끼우는 오류를 금지했다. [01강 / V01a / 00:17:05-00:18:02]
- 연속 숫자·호수에서 1과 2의 읽기가 일반 숫자와 달라질 수 있음을 수업에서 교정했다. 정확 음가는 화면 대조가 어려운 구간이 있어 전사 원문을 암기값으로 쓰지 않는다. [01강 / V01b / 00:00:08-00:08:25]

## 12. 수강생 답변과 강사 피드백

| 문제 | 수강생 원답 | 강사 지적 | 수정 답변 | 수정 이유·재발 방지 | 출처 |
| -- | -- | -- | -- | -- | -- |
| 그림 시간 | 그림과 다른 시각 | 그림이 답인데 수치를 바꾸면 오답 | 그림의 실제 시각을 한 문장으로 답 | 말하기 전에 수치 확인 | [01강 / V01a / 00:13:35-00:13:59] |
| 비교 | 哥哥比弟弟很高。 | `比` 비교문에서 `很` 사용 오류 | 哥哥比弟弟更高。 | `比…更…` 덩어리로 반복 | [01강 / P01 / 8페이지] |
| 기간 | 我10年工作了。 | 기간 위치 오류 | 我工作10年了。 | 시점/기간을 따로 표시 | [01강 / P01 / 11페이지] |
| 독서 동작 | 他们在图书馆做读书。 | 자연스러운 동사 결합이 아님 | 他们在图书馆看书。 | 명사 번역식 조합 금지 | [01강 / P01 / 13페이지] |
| 중국어 음성 답 | [확인 불가] | 양사·전치사·성조를 즉시 수정 | 화면/PDF의 문장 | 교정 구간을 녹화로 재청취 | [01강 / V01a / 00:28:53-00:48:56] |

`[확인 불가]`는 수강생의 중국어 원문을 음성만으로 확정할 수 없는 경우다. 이 경우 교정의 방향만 보존하고 문장을 만들어내지 않았다.

## 13. 강사가 반복한 내용

- Part 2는 4문항을 모두 맞혀야 한다는 정확도 원칙을 여러 차례 반복했다. [01강 / V01a / 00:01:18, 00:13:29]
- 발음·딕션·성조가 중요하다는 말은 오리엔테이션과 개별 교정 전후에 여러 차례 나왔다. [01강 / V01a / 00:11:00-00:12:12]
- Part 4가 3급 대비의 하이라이트이자 채점 기준이라는 설명을 반복했다. [01강 / V01a / 00:03:44-00:07:29]
- 익숙한 구조로 정확히 답하고 그림의 정보를 바꾸지 말라는 지시가 Part 2 전 구간에서 반복됐다. [01강 / V01a / 00:13:29-00:48:56]

## 14. 강사의 경고와 금지 사항

- Part 2에서 길게 답하려 하지 말고 그림과 다른 시간·수량을 말하지 않는다. [01강 / V01a / 00:13:29-00:13:59]
- `比` 비교문에 `很`을 넣지 않는다. [01강 / P01 / 8페이지]
- 세트 암기만 믿지 않는다. 최근 문제는 섞이므로 실제 듣고 답하는 능력이 필요하다고 했다. [01강 / V01a / 00:08:12-00:08:37]
- 사자성어·고급 표현을 늘리기 전에 발음 오류를 그대로 두지 않는다. [01강 / V01a / 00:12:05-00:12:12]
- Part 3 입력을 전부 질문으로 오해하지 않는다. 상대의 말에 자연스럽게 반응한다. [01강 / V01a / 00:02:18-00:03:17]

## 17. 이번 강의 핵심 10가지

- 1. Part 2는 네 문항 모두 정확히 답하는 목표다.
- 2. Part 3은 질문뿐 아니라 말에 반응하는 파트다.
- 3. Part 4는 3급 대비의 중심이다.
- 4. Part 4는 25초, 네 문장 이상을 준비한다.
- 5. 그림이 답의 기준이다.
- 6. 발음·딕션·성조를 우선한다.
- 7. 비교문에서 `比…更…`와 `没有…`를 구분한다.
- 8. 기간은 동사 뒤에 둔다.
- 9. 고정 답은 즉시 나오게 준비한다.
- 10. 세트 암기만으로 시험을 대비하지 않는다.
