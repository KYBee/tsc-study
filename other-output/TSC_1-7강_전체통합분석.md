## 3. 문제 유형별 완전 정리

### Part 1 자기소개

- 요구: 이름, 생년월일, 가족, 소속 네 고정 질문.
- 순서/템플릿: `我叫XX。` / `我生于…` / `我家有XX口人。` / `我在XX工作。`
- 길이: 각 10초이지만 미채점이므로 짧게 말한다.
- 주의: 미채점이라고 무응답하지 말고 발음 워밍업으로 활용한다. [01강 / P01 / 4-5페이지]

### Part 2 그림 보고 답하기

- 요구: 그림의 위치, 존재, 비교, 동작, 시간, 수량을 질문에 맞춰 말한다.
- 준비: 3초 동안 `누가/무엇이`, `어디`, `몇`, `어떤 관계`인지 먼저 본다.
- 구성: 질문의 의문사 자리에 그림의 답 정보를 넣어 한 문장으로 끝낸다.
- 대표 구조: `A比B更…`, `A没有B…`, `주어+在+장소/동작`, `장소+有+대상`.
- 질문과 그림이 다를 때: `不是，…`로 부정 후 실제 동작을 말한다. [07강 / V07 / 00:02:45-00:03:19]
- 막힘: 길이를 늘려 만회하려 하지 말고 확인한 정보만 정확히 말한다.
- 금지: `哥哥比弟弟很高`, `香蕉很更重`, 그림과 다른 시각·수량. [01강 / P01 / 8페이지] [07강 / V07 / 00:01:51-00:02:08]

### Part 3 대화 완성

- 요구: 질문 또는 진술을 듣고 상대가 기대하는 자연스러운 반응을 한다.
- 준비: 화면 한자 없이 2초이므로 구체 명사보다 `감사/부탁/초대/축하/곤란`의 기능과 상대를 먼저 잡는다.
- 답변: 쿠션·리액션 → 직접 수락/거절/공감 → 필요한 후속 질문·대안.
- 시작: `当然可以。`, `没问题。`, `是吗？`, `不好意思。`, `恭喜你！` 등 자료의 짧은 반응.
- 확장: `我来+동사`, 이유 한 문장, 다음 약속 한 문장을 붙인다.
- 길이: 15초이나 너무 길게 Part 4처럼 만들지 않는다. [07강 / V07 / 00:03:23-00:03:39]
- 막힘: 목적어 하나를 놓쳐도 요청·감사 등 패턴이 확실하면 안전한 반응을 먼저 한다.
- 금지: 모든 입력을 질문으로 오해, 한국어 문장을 만든 뒤 직역, 발음 불안정 고급어 과시.

### Part 4 간단하게 답하기

- 요구: 화면에 보이는 질문의 화제에 자신의 답을 25초로 설명한다.
- 준비 15초: 입장/사실 한 줄, 이유 두 줄, 경험·예 또는 정리 한 줄을 잡는다.
- 화면의 실제 STEP 구조: STEP1 직접 답 → STEP2 이유·세부/사례 → STEP3 `总之` 계열 정리. [06강 / V06 / 00:22:31-00:22:38]
- 확장법: 인물은 특징+행동 사례, 생활은 빈도+이유+효과, 경험은 사건 순서+감정+의미+향후 행동.
- 대표 주제: 상사·성격, 운동, 주말 기상, 요리, 외국어, 월급, 서점, 계절, 회사 환경, 분실 경험, 중고품, 여행, 이직.
- 길이: 4급 수준의 짧은 직답에서 끝내지 않고 네 문장 이상 수준을 준비한다.
- 막힘: 질문 한자의 핵심어를 읽고, 확실한 쉬운 이유 하나부터 시작한다.
- 금지: 불확실한 문법으로 마지막 시간을 억지로 채우기, 추상 형용사만 나열하기.

### Part 5 의견 확장

- 요구: 의견·사회 문제에 50초 동안 논리적으로 답한다.
- 준비 30초: 입장, 이유/장단점, 구체 예 또는 대책, 마무리 순서를 정한다.
- 화면 구조 예: `第一…第二…第三…以上是我的想法。` [06강 / V06 / 01:12:50-01:15:16]
- 장단점: `我觉得有利有弊。` → 장점 → 단점/조건 → 내 결론.
- 선택: 가격/스타일 중 하나를 고르고 월급·생활비 또는 유행·광고로 이유를 붙인다.
- 사회 의견: 문제 인식 → 개인 능력/의식 → 학교·사회 교육 → 제재/마무리.
- 막힘: 문제 문장을 반복만 하지 말고 쉬운 입장과 대책 한두 문장부터 말한다.
- 금지: `越来越很贵` 같은 정도 중복, 입장을 계속 바꾸기, 불확실한 고급어.

### Part 6·7

- Part 6은 구성과 시간만 1강 자료에서 확인됐고, 실제 답변 구조의 상세 훈련은 과정에서 거의 없다.
- Part 7은 그림 순서와 마지막 반전을 확인한다. 5강 DOCX의 미용실에서 잘못 파마한 이야기는 예고 수준이므로 완성 템플릿을 임의로 만들지 않는다. [05강 / D05 / -7P-]

## 4. 강사가 말한 고득점 전략 총정리

### 반드시 해야 하는 것

- 발음·딕션·성조를 수업 교정 구간과 녹음으로 다시 확인한다.
- Part 2 그림의 수치·대상·관계를 정확히 답한다.
- Part 3에서 상대 발화의 기능과 대상을 듣고 자연스럽게 반응한다.
- Part 4는 직답+이유+구체 예+정리로 25초를 준비한다.
- 틀린 답을 타이핑해 오답노트에 수정 문장으로 남긴다.

### 하면 좋은 것

- 전형적인 Part 4 모범 답은 소리 내어 외운다. [06강 / V06 / 00:13:32-00:13:47]
- 질문 한자의 핵심 뜻과 주제 어휘를 익힌다.
- 자기 가족·회사·취미 경험을 여러 주제에 재사용한다.
- 못 답한 문제를 다시 작성해 강사에게 보내 피드백받는다.

### 피해야 하는 것

- 오래된 세트가 그대로 출제될 것이라 믿는 통암기.
- 발음이 불안한 고급어, 한국어 직역, 문법상 가능하지만 실제로 어색한 표현.
- Part 3에서 어휘량을 보여주려는 장문.
- Part 4·5에서 시간만 채우려는 불확실한 문장.

### 감점 가능성이 있다고 말한 것

- 전치사·어순·문법 오류의 누적, 동문서답, 비교 정도 부사 중복, 그림과 다른 정보.
- 축하·소식의 당사자를 반대로 듣는 것. [04강 / V04c / 00:05:05-00:05:16]
- 마지막 5초에 문법이 틀린 말을 추가하는 것.

### 반복적으로 강조한 것

- 발음·성조, 쉬운 정확한 문장, Part 4의 중요성, 복습, 자기 답 오답 교정.

### 특정 문제에서만 적용되는 것

- Part 2는 길이보다 한 문장 정확도.
- Part 3은 질문이 아닌 진술에도 반응.
- Part 4는 화면 한자를 활용.
- Part 5는 장단점/대책을 순서화.
- Part 7은 마지막 그림의 반전 확인.

## 5. 강사가 제시한 공부법 총정리

강의 내용을 실제 실행 순서로만 재배열하면 다음과 같다.

1. 고정 Part 1 답과 Part 2 기본 구조를 소리 내어 말해 발음을 푼다. [01강 / P01 / 4-8페이지]
2. 그림 문제에서 틀린 비교·위치·수량 문장을 바로 고쳐 다시 말한다.
3. Part 3은 상황별(감사/부탁/제안/축하/직장 요청)로 첫 반응을 묶어 익힌다.
4. 수업 중 강사가 고친 성조와 문법을 녹화·전사에서 다시 찾는다. [01강 / V01a / 00:11:29-00:12:12]
5. 본인의 실제 답을 타이핑하고 수정 전/후를 오답노트에 남긴다. [04강 / V04c / 00:45:26-00:45:53]

## 8. 발음과 성조 통합

- 최다 반복 항목은 발음·딕션·성조다. 강사는 고급 표현을 덜 쓰더라도 또렷한 발음을 우선하라고 했다. [01강 / V01a / 00:11:00-00:12:12]
- `f`는 윗니와 아랫입술을 쓰는 입 모양을 직접 지도했다. [02강 / V02a / 초반]
- 연속 숫자·호수, 비교 `比/更`, `j/q/x` 뒤 모음, `z/c/s`와 `zh/ch/sh`, 계절·돈 관련 단어를 개별 교정했다.
- `旁边`의 `边`에는 얼화를 더하면 자연스럽다고 했다. [07강 / V07 / 00:01:06-00:01:19]
- 발음이 불확실하면 녹음해 강사에게 보내고, 수업 녹화의 교정 시점을 다시 확인한다.
- 강세·말하기 속도의 정량 기준, 억양 곡선은 자료에서 제시되지 않았다.

## 13. 원본 강의를 보지 않은 학습자를 위한 상세 설명

먼저 이 과정의 중심은 많은 어려운 말을 아는 것이 아니라 `듣고, 그림/질문의 핵심을 잡고, 통제 가능한 중국어로 정확히 답하는 것`임을 이해해야 한다. 1강은 Part 2와 3·4가 전체의 기초라고 설명하고, 이후 강의는 그 원칙을 실제 수강생 답에 적용한다.

Part 2는 그림 시험이다. 질문 문자가 없으므로 그림의 위치·수량·동작을 먼저 보고, 질문의 의문사 자리에 답을 넣는다. 답은 짧지만 비교나 수량 어순이 틀리면 안 된다. Part 3은 대화다. 상대가 감사했는지, 부탁했는지, 좋은 소식을 말했는지 알아듣고 `当然可以`, `恭喜你`, `不好意思` 같은 반응으로 시작한다. 길게 설명하기보다 다음 대화 차례가 자연스럽게 이어져야 한다.

Part 4부터는 자신의 이야기가 필요하다. 15초 동안 입장·이유·사례·마무리를 떠올리고 25초 동안 네 문장 이상 수준으로 말한다. 상사라면 성격과 도움 사례, 회사 환경이라면 식당·수영장과 실제 장점, 잃어버린 물건이라면 언제·어디서·왜 아쉬운지·앞으로 어떻게 할지를 말한다. Part 5는 이를 50초로 늘려 장단점이나 대책을 순서화한다.

외워야 하는 것은 모든 기출의 완성 답이 아니다. 고정 Part 1 답, Part 2 기본 구조, Part 3 첫 반응, 전형 Part 4 모범 답, Part 5 순서 표현을 우선한다. 비전형 문제는 자신의 가족·회사·취미 경험으로 만든다. 강사는 반복해서 녹음, 녹화 재확인, 오답 타이핑, 첨삭 제출을 권했다.

피해야 할 것은 한국어 직역, 발음이 불안한 고급어, 비교·전치사·어순 오류, 양만 긴 답, 마지막의 불확실한 덧붙임이다. 시험 전에는 새로운 지식을 더 넣기보다 이미 만든 답을 실제 시간으로 말하고 발음·성조와 문법을 확인한다.
