# 상위 백로그

백로그는 사용자 관점의 기능 단위로 유지한다. 실제 개발을 시작할 때 검수된 데이터와 결정된 기술 사항을 기준으로 세부 작업을 나눈다.

우선순위는 `P0`(선행 필수), `P1`(MVP 핵심), `P2`(MVP 이후 개선), `P3`(선택)으로 표시한다.

| ID | 우선순위 | 사용자 스토리 | 간단한 완료 조건 |
|---|---|---|---|
| `DOC-01` | P0 | 작업자로서 일관된 제품·데이터·교정 원칙을 확인하고 싶다. | 루트 지침과 관련 문서의 상태·용어가 일치한다. |
| `DATA-01` | P0 | 데이터 검수자로서 원본 Excel과 강의 분석 자료의 내용과 파일명을 변경 없이 보관하고 싶다. | 원본 파일명, 출처 메타데이터, 공개 가능 여부를 추적할 수 있다. |
| `DATA-02` | P0 | 데이터 검수자로서 문제를 추출하고 중복·언어·유형·출처를 단계적으로 검수하고 싶다. | 표본 문제가 원본 위치와 연결된 `verified` 상태에 도달한다. |
| `DATA-03` | P0 | 데이터 검수자로서 답변 없는 예상 문제도 정상적으로 관리하고 싶다. | `missing` 상태가 오류나 질문 검수 차단으로 처리되지 않는다. |
| `LEARN-01` | P1 | 학습자로서 Part 1~7의 목표, 준비 요령, 구조와 필수 표현을 보고 싶다. | 검수된 가이드와 출처, 세 언어 표현을 Part별로 볼 수 있다. |
| `LEARN-02` | P1 | 학습자로서 대표 문제를 보고 기본 답변과 자주 하는 실수를 학습하고 싶다. | 문제를 먼저 본 뒤 검수된 기본 답변과 오류 설명을 열어 볼 수 있다. |
| `ANSWER-01` | P1 | 학습자로서 한국어로 쓴 내용을 내 의미를 유지한 중국어 답변으로 만들고 싶다. | 새 경험을 만들지 않고 Part 구조와 세 언어 결과를 제공한다. |
| `ANSWER-02` | P1 | 학습자로서 내가 쓴 중국어를 최소한으로 교정받고 싶다. | 원래 표현을 최대한 유지하고 수정 전후와 이유를 보여준다. |
| `ANSWER-03` | P1 | 학습자로서 한국어와 중국어를 섞어도 하나의 중국어 답변으로 정리하고 싶다. | 두 언어의 의미 충돌을 임의 결정하지 않고 일관된 결과 형식을 제공한다. |
| `ANSWER-04` | P1 | 학습자로서 검토한 교정 결과를 나의 답변으로 저장하고 싶다. | 사용자 승인 결과만 개인 데이터로 저장하며 공용 모범답안과 구분된다. |
| `REVIEW-01` | P1 | 학습자로서 답변을 숨긴 문제로 저장한 답변을 회상하고 싶다. | 답변 보기 전에는 문제만 보이며 이후 기본 답변과 개인 답변을 구분해 볼 수 있다. |
| `REVIEW-02` | P1 | 학습자로서 문제를 `못 외움`, `헷갈림`, `외움`으로 표시하고 싶다. | 개인 `ReviewState`에서 상태를 저장·변경하고 약한 상태만 선택할 수 있다. |
| `MISTAKE-01` | P1 | 학습자로서 강사가 교정한 대표 오류를 모아 복습하고 싶다. | 오류 콘텐츠와 출처가 있고, 개인 학습 상태는 연결된 `ReviewState`에 있다. |
| `MISTAKE-02` | P1 | 학습자로서 내 답변에서 반복되는 개인 오류를 복습하고 싶다. | 개인 오류가 원래 사용자 답변과 연결되고 공용 오류와 구분된다. |
| `REVIEW-03` | P2 | 학습자로서 병음과 한국어 뜻을 숨겨 회상 난이도를 조절하고 싶다. | 각 표시 항목을 독립적으로 숨기고 다시 볼 수 있다. |
| `REVIEW-04` | P2 | 학습자로서 랜덤 또는 약점 우선 순서로 복습하고 싶다. | 랜덤과 `못 외움`·`헷갈림` 우선 방식을 선택할 수 있다. |
| `ANSWER-05` | P2 | 학습자로서 최소 교정, 쉽게 말하기, 자연스럽게, Level 8 확장을 구분해 받고 싶다. | 모드를 명시적으로 선택하며 결과와 목적이 섞이지 않는다. |
| `ACCOUNT-01` | P3 | 학습자로서 필요할 때 여러 기기에서 개인 기록을 이어 보고 싶다. | 인증·저장·보호 방식을 결정한 뒤 동기화 여부를 검증한다. |

## 현재 백로그에서 제외

녹음, 음성 인식, 음성 평가, 질문 음성 재생은 현재 우선순위에 넣지 않는다. 추후 필요성이 확인되기 전에는 개발 작업으로 세분화하지 않는다.
