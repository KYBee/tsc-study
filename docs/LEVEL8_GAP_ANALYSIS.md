# Level 8 목표 대비 강의 자료 공백 분석

## 목적과 적용 범위

이 문서는 현재 TSC Level 5이고 Level 8을 목표로 하는 학습자 관점에서 `other-output`의 TSC 1~7강 자료가 제공하는 기초와 부족분을 구분한다. 학습자는 중국 거주 경험이 있고 HSK 5급 240점 수준이므로, 기초 어휘를 무작정 늘리기보다 실수 감소, 답변 구조의 안정화, 개인 경험의 재사용과 시간 안의 논리적 확장이 중요하다.

현재 자료는 주로 2024년 TSC 3급 목표 강의 분석이다. 이 자료의 정확성·감점 방지 원칙은 Level 8 준비의 foundation으로 활용할 수 있지만, 과정 목표를 Level 8로 바꾸거나 확인되지 않은 공식 Level 8 채점 기준을 만들지 않는다.

## 직접 도움이 되는 기반

- 고급어보다 발음·딕션·성조와 쉬운 문장의 정확성을 우선한다.
- Part 2에서는 길이보다 그림의 대상·수량·비교·동작을 정확히 말한다.
- Part 3에서는 모든 발화를 질문으로 처리하지 않고 감사·부탁·제안·축하 등 기능에 먼저 반응한다.
- Part 4에서는 직답 뒤에 이유, 구체적 설명·경험과 정리를 붙인다.
- Part 5에서는 입장, 근거, 예·대책과 결론을 순서화한다.
- 전치사·어순·정도 표현 중복 같은 반복 오류를 수정 전후로 남긴다.
- 전형 답은 안정화하되 비전형 문제는 실제 개인 경험으로 준비한다.
- 마지막에 확신 없는 문장을 억지로 추가하지 않는다.

이 항목들은 강의 목표 수준과 별개로 실수를 줄이고 통제 가능한 답변을 만드는 데 유효하다. 다만 Level 8 달성을 보장하는 기준이나 공식 평가 항목으로 표시해서는 안 된다.

## 그대로는 부족한 부분

- Level 8의 공식 평가 기준과 등급별 성취 예시가 자료에 없다.
- 같은 문제에 대한 기본 답변과 검수된 Level 8 확장 답변의 비교쌍이 없다.
- 긴 답변에서 논리 연결, 세부화, 반론과 결론을 어느 수준까지 요구하는지 검증된 기준이 없다.
- 전체 문장 병음이 없는 표현과 교정 후보가 많다.
- 질문과 연결된 완성 중국어·전체 병음·전체 한국어의 `ModelAnswer`가 충분하지 않다.
- 학습자의 중국 거주 경험, 회사·가족·취미·성공·실패 사례를 재사용할 개인 경험 답변 뱅크가 없다.
- 실제 AI 최소 교정과 Level 8 확장 결과의 품질·안전성 검증이 없다.
- 발음 피드백 근거는 텍스트 지침에 머물며 실제 음성 평가가 연결되지 않았다.
- 시간 제한 드릴은 데이터로 구조화할 수 있지만 앱의 타이머·녹음·자가 점검 흐름은 아직 없다.

|---|---|---|---|
| 1 | 이름·생년월일·가족·소속의 짧은 고정 답, 발음 워밍업 | 실제 학습자 정보로 검수된 답변, 날짜·숫자·소속 발음 검수 | 학습자 승인 개인 정보, 원어민 또는 강사 발음 검수 |
| 2 | 비교·위치·수량·동작·부정의 정확한 한 문장 원칙 | 다양한 그림 세트, 전체 질문·답변 삼언어, 시각 자료 권리, 오류 유형별 충분한 표본 | 12개 그림 세트 전체 검수, 원본 화면과 답변의 ID 연결 |

| 5 | 입장 → 근거·예·대책 → 결론과 순서 표현 | 50초 분량의 검수된 전체 답변, 반론·조건·구체 사례 확장, 사회 주제 자료 | 출처·권리를 확인한 장문 답변과 구조 세그먼트 |
| 6 | 과정에서 문항 수·시간 같은 개요 언급만 확인 | 실제 상황 유형, 역할·요구 행동, 사과·설명·대안 구조, 질문·답변·교정 표본이 거의 없음 | 별도의 Part 6 강의·교재·문제와 강사 검수 |
| 7 | 그림 순서와 마지막 반전을 보라는 예고 수준 | 완전한 시각 세트, StoryGuide, 90초 이야기 표본, 연결어, 사건 전개와 결말 검수 부족 | 권리 확인 VisualAsset, 검증된 QuestionVisualSet, StoryGuide와 별도 ModelAnswer |

## 근거와 언어 데이터 공백

### 출처

저장소에는 분석 Markdown과 PDF·DOCX 텍스트 추출본만 있고, 분석이 참조한 원본 MP4·PDF·DOCX는 없다. 타임스탬프와 원본 파일명 주장은 보존하되 현재 레코드를 `verified`로 승격할 수 없다. 공개 사용 가능 여부도 별도 확인이 필요하다.

### 중국어·병음·한국어

표현 암기장의 다수 병음은 단어 일부, `문서에 병음 표기`, `화면 병음` 또는 `자료에서 확인 불가`다. 이 값을 전체 문장 병음으로 사용할 수 없다. 교정 후보 9개도 모두 수정 문장 전체 병음이 부족하다. 특히 `每天…` 후보는 통합 분석과 PDF 직접 텍스트의 전후 문장까지 다르고, 일부 후보는 정확한 수정 전 중국어가 없다. 따라서 누락을 생성하거나 한쪽 문구를 선택하지 않고 검수 대기 상태로 유지해야 한다.

### 답변

템플릿, 표현 목록, 답변 구조, Part 7 이야기 포인트는 `ModelAnswer`가 아니다. 특정 `Question` 또는 `VisualQuestion`, 완성 중국어, 전체 병음, 전체 한국어와 실제 Source 위치가 모두 확인될 때만 출처 답변 후보로 반입한다.

## 학습자 개인 데이터 공백

Level 8 준비에서 가장 큰 추가 자산은 학습자 본인의 경험을 정확한 중국어로 재사용할 수 있는 데이터다.

- 가족, 중국 생활, 직장, 여행, 운동, 갈등, 선택, 성공·실패의 승인된 사실
- 같은 경험을 Part 3·4·5에서 길이와 구조만 바꿔 사용하는 표현
- 반복되는 개인 오류와 최소 교정 이력
- 말하기 어려운 어휘를 쉬운 표현으로 바꾼 기록
- 질문 관련성, 논리 연결, 불확실한 사실을 표시한 검수 메모

개인 경험은 `UserAnswer`와 개인 `Correction`으로 공용 강의 데이터와 분리한다. 사용자가 말하지 않은 경험을 만들어 채우지 않는다.

## 앱 기능 공백

- 실제 AI 공급자와 모델, 서버 측 비밀키 경계가 미결정이다.
- 현재 mock 교정은 한 계약 사례만 지원하며 일반 중국어 교정 능력이 없다.
- 시간 제한 준비·답변 드릴의 타이머, 회상 체크와 결과 기록이 없다.
- 강의가 권한 자기 녹음은 현재 MVP 우선순위에서 제외되어 있다.
- 발음·성조를 사람이 검수하거나 향후 음성 피드백으로 연결하는 계약이 없다.
- `LearningExpression`, `PronunciationItem`, `PracticeDrill`, `CourseInsight`를 표시·복습하는 화면 계약이 아직 없다.
- 약점 기반 복습은 `ReviewState`를 넘어 어떤 근거로 추천할지 정하지 않았다.

## 결론

현재 강의 자료는 Level 8 답변을 직접 제공하는 코퍼스가 아니라 정확성·감점 방지와 기본 구조를 안정화하는 3급 과정 근거다. 먼저 근거 수준을 보존한 working 데이터를 검수하고 전체 253개 문제 및 개인 경험과 연결해야 한다. 그다음 기본 답변과 출처가 분리된 `self_created` Level 8 확장 답변을 교사 검수로 만들어야 하며, 공식 기준이 확인되지 않은 길이·어휘·점수 규칙은 추가하지 않는다.
