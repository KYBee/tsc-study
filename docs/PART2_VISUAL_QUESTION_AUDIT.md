## 데이터 보존과 provenance

- VisualQuestion 48개와 ModelAnswer 48개의 SHA-256은 작업 전후 동일하다.
- 기존 asset ID와 filename은 유지했다.
- importer manifest에서 새 교체본을 `generated_replacement`로 표시하고,
  기존 묶음 자산은 `named_bundle_asset`로 구분한다.
- audited archive 기준 PNG 바이트 보존과 SHA·크기·치수를 검증한다.
- 생성 교체는 출처 답변이나 이미지 공개 권리를 승인한다는 의미가 아니다.
