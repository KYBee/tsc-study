# MVP 범위

## 범위 정의

MVP는 아래 네 가지 메뉴가 하나의 학습 순환을 이루는 상태를 뜻한다. 로드맵에서는 데이터 준비와 기능을 여러 Phase로 나누어 순차적으로 구현한다.

`파트 구조 학습 → 나의 답변 작성·교정 → 저장한 답변 복습 → 반복 오류 복습`

## 포함 기능

### 1. 파트별 학습

Part 1~7별로 다음 정보를 제공한다.

- 파트의 목표
- 준비 요령
- 권장 답변 구조
- 반드시 외울 표현
- 대표 문제
- 기본 모범답안
- 자주 하는 실수

현재 확정된 대표 구조는 다음과 같다.

| Part | 권장 구조 |
|---|---|
| Part 2 | 핵심 정보 파악 → 짧고 정확한 한 문장 |
| Part 3 | 즉각 반응 → 이유 또는 상황 → 후속 행동이나 대안 |
| Part 4 | 직접 답변 → 이유 → 구체적인 설명이나 경험 → 결론 |
| Part 5 | 입장 → 근거 1 → 근거 2 → 예시 → 결론 |
| Part 6 | 상황 확인 → 반응 또는 사과 → 문제 설명 → 해결책이나 대안 |
| Part 7 | 배경 → 사건 시작 → 문제 발생 → 결과 → 마무리 |

Part 1의 세부 구조와 각 파트의 시험 규칙은 검수된 강의 자료를 바탕으로 작성하며 현재 임의로 만들지 않는다.

**완료 조건**

- Part 1~7을 구분해 조회할 수 있다.
- 각 파트의 검수된 가이드 항목과 출처를 확인할 수 있다.
- 대표 문제의 중국어, 병음, 한국어 뜻을 함께 볼 수 있다.
- 선택된 대표 문제에는 검수된 기본 모범답안을 제공한다.
- 답변이 없는 일반 예상 문제도 오류 없이 표시할 수 있다.

### 2. 나의 답변 만들기

- 한국어, 중국어, 한국어·중국어 혼합 입력을 받는다.
- 한국어는 의미를 유지한 자연스러운 중국어로 변환하고 해당 Part 구조로 정리한다.
- 중국어는 사용자의 단어와 구조를 최대한 재사용해 최소한으로 교정한다.
- 혼합 입력은 의미를 유지하면서 자연스러운 중국어 답변으로 통일한다.
- 결과에는 교정된 중국어, 전체 병음, 한국어 뜻, 수정 전후, 수정 이유, 구조 구분을 포함한다.
- 사용자가 결과를 자신의 답변으로 저장할 수 있다.

**완료 조건**

- 세 입력 유형을 구분해 같은 결과 형식으로 반환한다.
- 사용자가 말하지 않은 개인 정보나 경험을 추가하지 않는다.
- 질문과 관련 없는 내용은 수정 이유와 함께 알린다.
- 최소 교정과 “Level 8답게 확장”을 동일 결과로 섞지 않는다.

### 3. 문제 복습

- 문제를 먼저 보여주고 답변은 기본적으로 숨긴다.
- 답변 보기 시 기본 모범답안과 사용자가 저장한 답변을 구분해 보여준다.
- 학습 상태는 `못 외움`, `헷갈림`, `외움` 세 가지로 관리한다.
- `못 외움`과 `헷갈림`을 우선 복습할 수 있다.

**완료 조건**

- 답변을 보기 전에 문제만으로 회상할 수 있다.
- 공용 모범답안과 개인 답변이 명확히 구분된다.
- 세 학습 상태를 저장하고 변경할 수 있다.
- 약한 상태의 문제만 선택해 복습할 수 있다.

### 4. 실수 노트

- 강사가 교정한 대표 오류와 사용자 답변 교정 중 발생한 개인 오류를 구분한다.
- 잘못된 중국어, 올바른 중국어, 병음, 한국어 뜻, 오류 유형, 수정 이유, 출처, 학습 상태를 관리한다.

**완료 조건**

- 대표 오류와 개인 오류를 출처 유형으로 구분해 조회할 수 있다.
- 각 오류에 필요한 언어 정보와 수정 이유가 있다.
- 학습 상태를 갱신하며 다시 볼 수 있다.

## MVP에 포함하지 않는 기능

- 녹음, 음성 인식, 발음·음성 평가
- 질문 음성 재생
- 자동으로 대량 생성한 문제나 모범답안
- 기본 교정에 자동으로 포함되는 Level 8 확장
- 로그인, 기기 간 동기화, 공개 배포 같은 선택 기능
- 확인되지 않은 실제 시험 규칙이나 강의 내용의 생성

## 범위 원칙

- 답변이 없는 예상 문제는 MVP 데이터 오류가 아니다.
- 기능 구현보다 데이터의 출처와 검수 상태를 먼저 확인한다.
- 기술 스택과 데이터 저장 형식은 별도 결정 전까지 이 문서에서 확정하지 않는다.
