# 사용자 흐름

이 문서는 화면 디자인이나 UI 코드를 정의하지 않는다. 사용자가 목표에 도달하기 위해 거치는 정보와 행동의 순서만 설명한다.

## 1. 파트별 학습

1. 사용자가 Part 1~7 중 하나를 선택한다.
2. 파트의 목표와 준비 요령을 확인한다.
3. 권장 답변 구조를 단계별로 확인한다.
4. 중국어·병음·한국어 뜻이 함께 있는 필수 표현을 학습한다.
5. 대표 문제를 먼저 읽고 답변을 떠올린다.
6. 답변 보기를 선택해 기본 모범답안과 구조 구분을 확인한다.
7. 자주 하는 실수를 확인한다.
8. 관련 문제 복습 또는 나의 답변 만들기로 이동한다.

답변이 없는 예상 문제라면 답변을 임의 생성해 채우지 않는다. `missing` 상태를 알리고 나의 답변 작성이나 향후 모범답안 작업으로 이어갈 수 있다.

## 2. 한국어 또는 중국어로 나의 답변 만들기

1. 사용자가 문제와 Part를 선택한다.
2. 한국어, 중국어 또는 두 언어를 섞어 자신의 답변을 입력한다.
3. 시스템이 입력 언어와 질문 관련성을 확인한다.
4. 한국어는 의미를 유지한 중국어로 정리하고, 중국어는 원래 단어와 구조를 살려 최소 교정하며, 혼합 입력은 자연스러운 중국어로 통일한다.
5. 결과에서 다음 항목을 확인한다.
   - 교정된 중국어
   - 전체 병음
   - 한국어 뜻
   - 수정 전후 표현과 간단한 이유
   - Part 답변 구조별 구분
6. 사용자가 결과를 검토한다. 확신할 수 없는 부분은 확정 결과가 아니라 확인 필요로 표시한다.
7. 사용자가 승인한 결과만 `나의 답변`으로 저장한다.

기본 흐름은 최소 교정이다. “Level 8답게 확장”은 향후 사용자가 별도로 선택하는 흐름으로 분리한다.

## 3. 저장한 답변 복습하기

1. 사용자가 전체 문제 또는 `못 외움`·`헷갈림` 문제를 선택한다.
2. 시스템이 문제의 중국어·병음·한국어 뜻 중 현재 설정에 맞는 정보를 보여주고 답변은 숨긴다.
3. 사용자가 저장한 자신의 답변을 말하거나 떠올린다.
4. 답변 보기를 선택한다.
5. 기본 모범답안이 있으면 표시하고, 사용자의 저장 답변과 명확히 구분한다.
6. 사용자가 `못 외움`, `헷갈림`, `외움` 중 하나를 선택한다.
7. 선택한 상태를 개인 `ReviewState`에 저장하고 다음 문제로 이동한다.

기본 모범답안이 없어도 사용자의 저장 답변만으로 복습할 수 있다.

## 4. 실수 노트 복습하기

1. 사용자가 강의의 대표 오류 또는 자신의 개인 오류를 선택한다.
2. 시스템이 잘못된 중국어를 먼저 보여준다.
3. 사용자가 올바른 표현을 떠올린다.
4. 정답 보기를 선택해 올바른 중국어, 병음, 한국어 뜻, 오류 유형과 수정 이유를 확인한다.
5. 출처가 강의 교정인지 개인 답변 교정인지 확인한다.
6. 사용자가 학습 상태를 선택하고 해당 오류를 대상으로 하는 개인 `ReviewState`에 저장한다.
7. `ReviewState`가 `못 외움` 또는 `헷갈림`인 오류를 우선해 다음 복습을 이어간다.
