# 원본 Excel 향후 매핑

## 범위

이 문서는 원본 Excel을 다음 단계에서 어떻게 분리·검수할지 정리한 계획이다. 이번 단계에서는 CSV·JSON 변환, 행 추출, 이미지 추출, 데이터베이스 설계나 모범답안 생성을 수행하지 않는다. 아래의 새 엔터티 이름은 개념 후보이며 기술 스택이나 최종 스키마를 확정하지 않는다.

## 공통 원칙

- `raw` Excel의 내용과 원래 파일명을 유지하고 직접 수정하지 않는다.
- 원본 셀은 시트명과 행 또는 블록 ID로 다시 찾을 수 있어야 한다.
- 질문과 모범답안은 별도 데이터로 관리하며 `Question` 1개에 `ModelAnswer` 0개 이상을 연결할 수 있게 한다.
- 답변이 없는 질문은 정상이며 임의 답변을 생성하지 않는다.
- 공용 콘텐츠와 사용자별 `UserAnswer`·`ReviewState`·개인 메모를 분리한다.
- 자료 등급, 원문성, 출처를 임의로 합치거나 바꾸지 않는다.
- 현재 값의 중국어, 병음, 한국어는 이번 단계에서 교정하지 않는다.

## 시트별 매핑 후보

| 원본 시트 | 향후 매핑 후보 | 원칙 |
|---|---|---|
| 문제은행 | `Question`, `Source` 연결, 공용 답변 포인트 보조 정보, `ReviewState`, `UserAnswer` 또는 개인 메모 | 공용 열과 개인 열을 분리한다. 기존 ID를 유지하고 답변 포인트를 완성된 `ModelAnswer`로 보지 않는다. |
| 시험 구조 | `PartGuide` 또는 시험 참고 정보 | `Question`으로 직접 가져오지 않는다. |
| 요약 | 검증 통계와 `PartGuide` 참고 정보 | 문제 수는 `문제은행` 실제 행 재집계를 기준으로 비교한다. |
| 공식·참고 링크 | `Source` | URL은 이번 단계에서 방문하거나 진위를 검증하지 않는다. |
| 그림 활용 안내 | `PartGuide`와 시각 자료 사용 안내 | 확인되지 않은 시험 규칙이나 권리 상태를 새로 만들지 않는다. |
| Part2 그림 연습 | `VisualQuestionSet`, `VisualAsset`, 필요 시 `Question` | 이미지는 Excel 안에 유지한다. 그림 세트 ID와 문항 번호로 구조를 보존한다. |
| Part2 정답 | Part 2 그림 질문의 `ModelAnswer` 후보 | 일반 `문제은행` 전체의 답변으로 취급하지 않고 그림 질문과 복합 키로 연결한다. |
| Part7 스토리 그림 | `VisualStorySet`, `VisualAsset` | 이미지를 추출하지 않고 그림 세트 ID와 배치 구조를 보존한다. |
| Part7 정답 포인트 | `AnswerPoint`, `StoryGuide` 또는 `PartGuide` 보조 데이터 | 완성된 중국어 모범답안으로 간주하지 않는다. |
| 공식 샘플 이미지 | `VisualAsset` | `rights_status`를 `review_needed`로 유지하고 공개 가능 여부를 별도 확인한다. |

## 문제은행 컬럼 매핑

### 공용 데이터 후보

| Excel 컬럼 | 향후 대상 | 매핑 메모 |
|---|---|---|
| ID | `Question.question_id` 후보 | `P1-001` 같은 기존 값을 유지한다. |
| Part | `Question.part` | 1~7 범위를 검수한다. |
| 유형 | `Question.question_type` | 원본 값을 임의로 표준화하지 않는다. |
| 중국어 문제/상황 | `Question.question_zh` | raw 값을 유지하고 향후 표본에서 정규화 여부를 기록한다. |
| 병음 | `Question.question_pinyin` | 이번 단계에서는 표기나 띄어쓰기를 교정하지 않는다. |
| 한국어 뜻/상황 | `Question.question_ko` | 이번 단계에서는 번역을 교정하지 않는다. |
| 자료 등급 | 공용 출처·분류 메타데이터 후보 | 현재 값을 유지한다. 최종 필드 위치는 미결정이다. |
| 출처 | `Source` 연결 후보 | 출처 레코드 검수 전 확정 연결하지 않는다. |
| 출처 URL | `Source` 참고 정보 후보 | 빈 값은 허용하며 URL을 이번 단계에서 방문하지 않는다. |
| 원문성 | 공용 provenance 메타데이터 후보 | 실제 원문, 정규화, 변형을 구분하는 원본 값을 유지한다. |
| 답변 포인트 | 공용 Question 영역의 보조 정보 후보 | 공용 추출 범위에는 포함하되 `Question` 필드 또는 별도 `AnswerPoint` 중 최종 위치는 미결정이다. 완성된 `ModelAnswer`로 간주하지 않는다. |

현재 `DATA_SCHEMA.md`에 없는 자료 등급, 원문성, 답변 포인트 필드는 표본 검수 후 스키마 확장 또는 보조 엔터티 여부를 결정한다. 원본 열을 맞추기 위해 기존 스키마를 이번 단계에서 바꾸지 않는다.

### 개인 데이터로 분리할 컬럼

| Excel 컬럼 | 향후 대상 | 현재 값과 처리 계획 |
|---|---|---|
| 연습 상태 | `ReviewState.learning_status` | 253행 모두 `미연습`이다. 현재 `ReviewState`의 세 상태에 없는 값이므로 변환하지 않는다. 향후 “상태 레코드 없음”으로 볼지 초기 상태를 별도로 둘지 결정한다. |
| 최근 연습일 | `ReviewState.last_reviewed_at` | 253행 모두 비어 있다. 빈 값은 복습 이력이 없는 상태로 다룬다. |
| 내 답변 메모 | `UserAnswer` 또는 별도 개인 메모 | 253행 모두 비어 있다. 공용 `Question`에는 넣지 않는다. 최종 저장 방식은 미결정이다. |

학습자의 `못 외움`, `헷갈림`, `외움` 상태는 `ReviewState`에서만 관리한다. Excel의 개인 열을 공용 질문이나 공용 교정 콘텐츠로 옮기지 않는다.

## Part 2 그림과 정답 연결

1. `Part2 그림 연습`은 `P2-V01`~`P2-V12`의 그림 세트 12개로 구성된다.
2. 각 세트에는 `Q1`~`Q4`의 중국어·병음·한국어 질문이 있어 총 48문항이다.
3. `Part2 정답`에는 같은 그림 ID와 문항 번호에 해당하는 48행이 있다.
4. 향후 연결 키는 `(그림 ID, 문항)`을 사용한다. 원본의 `Q1` 표기와 숫자 문항 값은 명시적으로 정규화한 뒤 비교하고, 원본 값도 보존한다.
5. 조사 결과 48개 연결 키와 세 언어 질문이 빠짐이나 중복 없이 대응한다.
6. 추천 답변, 답변 병음, 한국어 뜻은 연결이 검수된 뒤 `ModelAnswer` 후보로 분리한다. 이번 단계에서는 추출하지 않는다.

`문제은행`의 `P2-001`~`P2-048`은 `P2-V01` 같은 그림 세트 ID와 다른 체계이며, 두 목록의 질문도 행 순서 기준으로 같지 않다. 그림 연습 48문항 중 18개 발생만 세 언어가 `문제은행`의 14개 ID와 정확히 일치하고 일부 ID는 여러 그림에서 재사용된다. 나머지 30개는 중국어 문장도 정확히 일치하지 않는다. 번호나 텍스트만으로 자동 연결하지 않고 향후 `(그림 ID, 문항) → question_id` 연결 대응표를 별도로 검수한다.

## Part 7 그림과 정답 포인트 연결

1. `Part7 스토리 그림`은 `P7-V01`~`P7-V12`의 그림 세트 12개다.
2. `Part7 정답 포인트`의 `그림 ID`도 같은 12개로 빠짐이나 중복 없이 대응한다.
3. 향후 연결 키는 `그림 ID`다.
4. 한국어 상황, 추천 이야기 흐름, 권장 중국어 연결어, 자료 성격은 `AnswerPoint`, `StoryGuide` 또는 `PartGuide` 보조 데이터 후보다.
5. 완성된 중국어·병음·한국어 답변 묶음이 아니므로 `ModelAnswer`로 바로 가져오지 않는다.

`문제은행`의 `P7-001`~`P7-012`은 별도 ID 체계다. 숫자 접미사와 상황상 12개 대응 후보가 있지만 Excel 안에 직접 연결 키가 없고 문구도 요약·변형되어 있다. 이 관계는 추론 후보로만 기록하고 다음 표본 검수 전에는 자동 연결하지 않는다.

## 질문과 모범답안 상태

- `문제은행`의 각 행은 우선 `Question` 후보로 다룬다.
- `답변 포인트`가 있어도 `ModelAnswer`가 존재한다고 간주하지 않는다.
- Part 2 추천 답변은 해당 그림 질문과의 연결 및 출처를 검수한 후에만 `ModelAnswer` 후보가 된다.
- Part 7 정답 포인트는 답변 작성 보조 자료이며 `ModelAnswer`가 아니다.
- 모범답안이 없는 질문은 `answer_status: missing`에 해당하는 정상 상태다.
- 향후 기본 답변과 Level 8 확장 답변은 서로 다른 `answer_variant`로 관리한다.

## 다음 표본 추출 단계

1. Part별 대표 문제와 Part 2·7 그림 세트의 소수 표본 범위를 정한다.
2. 각 표본에 `source_id`와 시트·행 또는 블록 ID인 `source_locator`를 부여한다.
3. 공용 질문 열과 개인 학습 열을 논리적으로 분리해 매핑을 시험한다.
4. 중국어·병음·한국어와 유형을 원본과 대조하되, 수정이 필요하면 raw가 아닌 파생 데이터에 변경 이유를 기록한다.
5. 자료 등급, 원문성, 출처 URL 누락의 의미와 `Source` 연결을 표본 단위로 검수한다.
6. Part 2 복합 키와 Part 7 그림 ID 연결을 표본으로 재검증한다.
7. `미연습`의 `ReviewState` 처리와 개인 메모의 최종 엔터티를 결정 대상으로 남긴다.
8. 표본 결과를 근거로 기준 데이터 형식을 결정할지 검토한다. 현재 Excel, CSV, JSON 중 어느 것도 기준으로 확정하지 않는다.
