# 프로젝트 개요

## 사용자 배경

주 사용자는 현재 TSC Level 5이며 Level 8을 목표로 한다. 중국 거주 경험이 있고 HSK 5급 240점 수준의 기반을 갖추고 있어, 기초 중국어를 처음부터 학습하는 것보다 시험 답변의 정확성과 구조를 다듬는 것이 중요하다.

현재 보유한 자료에는 여러 TSC 강의 분석, 강의에서 추출한 문제와 유형, 예상 문제 Excel, 강사가 교정한 잘못된 문장과 올바른 문장, 일부 모범답안이 있다. 예상 문제에는 답변이 없을 수 있으며 이는 정상적인 작업 상태다.

## 해결하려는 문제

- 알고 있는 중국어도 말하기 답변에서 문법, 어순, 단어 선택 실수로 정확하게 전달하지 못한다.
- 파트에 맞는 답변 구조가 자동화되지 않아 제한된 준비 시간에 내용 구성이 흔들린다.
- 교정받은 표현과 개인 오류가 흩어져 있어 반복 학습하기 어렵다.
- 문제는 있지만 답변이 없는 자료를 검수하고 답변으로 발전시키는 일관된 작업 공간이 없다.
- 어려운 표현을 늘리는 방식이 사용자의 기존 표현과 실제 경험을 불필요하게 바꿀 수 있다.

## 제품 목표

1. 사용자가 반복하는 중국어 오류를 찾아 최소한으로 교정한다.
2. Part 1~7의 목표, 준비 요령, 답변 구조와 필수 표현을 반복 학습하게 한다.
3. 사용자가 자신의 의미와 경험을 담은 답변을 만들고 저장해 암기하게 한다.
4. 답변 없는 예상 문제를 정상적으로 보관하고 검수하며 모범답안을 점진적으로 만든다.
5. 강의 출처 데이터, 자체 제작 데이터, 개인 학습 데이터를 분리해 신뢰성을 유지한다.

## 제품이 하지 않는 일

- 기초 중국어 전 과정을 가르치는 종합 어학 서비스
- 처음부터 어려운 표현을 강제로 추가하는 고급 작문 서비스
- 확인되지 않은 시험 규칙이나 강의 내용을 생성하는 서비스
- 사용자가 말하지 않은 개인 경험을 대신 만드는 서비스
- 현재 우선순위에서 녹음, 음성 인식, 음성 평가, 질문 음성 재생을 제공하는 서비스

## Level 5에서 Level 8로 가기 위한 학습 방향

Level 8 목표는 표현 난이도만 높이는 것으로 다루지 않는다. 먼저 이미 아는 단어와 문장 구조를 정확하게 사용하고, 파트별 구조에 맞게 이유·예시·결론을 연결하며, 반복되는 오류를 줄이는 데 집중한다.

기본 교정은 사용자의 원래 의미와 표현을 최대한 유지한다. 정확한 기본 답변이 안정된 뒤에만, 사용자가 명시적으로 요청한 경우 별도의 “Level 8답게 확장” 결과를 제공한다. 구체적인 시험 채점 규칙은 확인된 자료가 들어오기 전까지 가정하지 않는다.
