# Part 4 답변 만들기·암기 UX 구현 계획

## 목표

기존 Part 4 working 50문제와 자유 입력 `PracticeDraft`를 유지하면서 질문 이해, 답변 설계, 구조별 작성, 답변 확인, 암기·회상으로 이어지는 기본 학습 흐름을 추가한다.

## 구현 순서

1. `PracticeDraft`에 선택적 설계·구조화 필드를 추가하고 `ReusablePhrase`, `RecallAttempt`를 개인 엔터티로 정의한다.
2. 학습 IndexedDB를 v3로 올려 두 신규 store를 추가한다. v2의 답변·초안·교정·복습 상태를 그대로 보존하는 테스트를 먼저 작성한다.
3. 구조화 답변 합치기, 기존 자유 입력 호환, 회상 결과→`ReviewState` 매핑을 순수 함수로 만들고 단위 테스트한다.
4. 문제 상세을 질문 이해 단계로 정리하고, 답변 화면에 설계·작성·완성·암기 단계를 구현한다.
5. 홈, 문제 목록, 나의 답변에 작성·완료·암기 상태와 주요 진입점을 반영한다.
6. 문서 계약을 additive하게 갱신하고 전체 자동 검증 및 320px 실제 브라우저 흐름을 확인한다.
