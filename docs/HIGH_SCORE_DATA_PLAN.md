# 고득점 목표 데이터 계획

## 목적

현재 Level 5 학습자가 Level 8을 목표로 할 때 필요한 데이터를 근거·검수 순서로 확장한다. 현재 강의는 3급 목표 과정이므로 정확성·감점 방지의 foundation으로 사용하고, Level 8 확장 데이터는 강의 출처와 분리된 `self_created` 콘텐츠로 별도 검수한다.

아래 우선순위는 제품·데이터 의존 순서다. 공식 Level 8 채점 기준이나 반복 횟수·복습 간격을 임의로 만들지 않는다.

## 1. 강의 기반 정확성·감점 방지 데이터

| 항목 | 내용 |
|---|---|
| 필요한 데이터 | `PartGuide`, `LearningExpression`, `PronunciationItem`, `PracticeDrill`, `CourseInsight`, 조건을 충족한 공용 `Correction` |
| 기존에 있는 데이터 | 통합 분석, 7개 상세 분석, 6개 study 문서, PDF·DOCX 추출 Markdown |
| 부족한 데이터 | 원본 영상·문서, 교정 문장 전체 병음·한국어, 일부 화면 충돌 해결 |
| 앱에서 사용할 화면 | 파트 상세, 답변 구성 힌트, 실수 노트, 후속 표현·발음 학습 화면 |
| 구현 우선순위 | `P0` — 전체 문제 연결과 답변 생성 전에 근거를 정리 |
| 검수 조건 | `evidence_kind`와 실제 Markdown 위치 확인, 3급 과정 맥락 보존, 누락 병음 미생성, 생성 학습 자료를 강사 발언으로 표시하지 않음 |

## 5. 강의와 분리된 self_created Level 8 확장 답변

| 항목 | 내용 |
|---|---|
| 필요한 데이터 | 기본 답변과 별도인 `level_8_expansion`, 확장 근거, 구조 차이, 개인 사실 보존 검수 |
| 기존에 있는 데이터 | 최소 교정/Level 8 확장 모드 분리 원칙과 Part별 기본 구조 |
| 부족한 데이터 | 공식 또는 전문가 검수 기준, 같은 질문의 수준별 비교쌍, 충분한 교사 검수 답변 |
| 앱에서 사용할 화면 | 교정 결과의 별도 확장 탭, 기본 답변과 확장 답변 비교 |

| 검수 조건 | `provenance_kind = project_created`, 강의 출처와 분리, 사용자 사실 불변, 어려운 표현을 강제로 추가하지 않음, 공식 Level 8 기준이라고 단정하지 않음 |

## 단계별 종료 기준

현재 앱에는 Part 1·3·4·5·6 working Question 193개와 Part 2
VisualQuestion 48개가 연결되어 사용자가 직접
PracticeDraft·ReusablePhrase·RecallAttempt·ReviewState를 쌓을 수 있다.
Part 2 출처 ModelAnswer 48개는 `review_needed` 상태로만 비교하며 기본
정답이나 Level 8 답변으로 승인한 것이 아니다. 이는 개인 경험 데이터 입력
기반이며 reviewed 승격이나 고득점 답변 준비 완료를 뜻하지 않는다. Part 2
권리·언어·답변 검수, Part 7 시각 학습과 Part 6 상세 훈련 보강은 계속 별도
우선 과제다.

1. working 반입은 모든 레코드가 실제 Source와 `evidence_kind`를 갖고 `review_needed` 이하일 때 완료한다.
2. reviewed 공용 데이터 승격은 중국어·전체 병음·한국어, 출처와 권리 검수가 끝난 레코드에만 적용한다.
3. 기본 답변이 없는 Question은 오류가 아니며 학습·개인 답변 작성은 계속 가능해야 한다.
4. Level 8 확장 데이터는 강의 기반 콘텐츠와 출처·변형·검수 상태를 분리한 뒤에만 노출한다.
5. 개인 데이터는 reviewed 공용 JSON에 포함하지 않고 현재 브라우저 IndexedDB 경계를 유지한다.
6. `full-import-v1`의 자동 연결과 후보는 별개다. Part 2 엄격 일치 18건 외의 관계는 사람 승인 전 canonical 연결로 승격하지 않는다.
