## V03 근거 처리

원본 workbook `Part7 정답 포인트!A4:E4`는 `수박이 사라져 아이를 의심했지만
실제로는 강아지가 먹었다`, `이웃 방문 → 수박 실종 → 아이를 혼냄 → 강아지가
범인`을 기록한다. 귤은 StoryGuide의 사건 원인이 아니므로 StoryGuide를 귤
이야기로 바꾸지 않았다. filename은 기존 asset ID 호환을 위해 유지하고 CSV
설명만 현재 그림인 `이웃이 수박 한 통을 준다`로 갱신했다.

## 데이터·권리 경계

- StoryGuide와 link candidate JSON의 SHA-256은 작업 전후 동일하다.
- 확정 QuestionVisualSet 관계는 계속 0개이며 후보 12건을 승인하지 않았다.
- 교체한 7장은 manifest에서 `generated_replacement`로 구분한다.
- StoryGuide는 ModelAnswer로 변환하지 않았고 ModelAnswer 수는 0개다.
- 이미지 권리는 계속 `review_needed`, `public_allowed = false`다.
