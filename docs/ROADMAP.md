# 로드맵

각 Phase는 앞 단계의 문서와 데이터를 검토한 뒤 진행한다. MVP 구현 기준과 첫 수직 기능의 패키지는 결정했지만 일정, 실제 AI·백엔드와 장기 패키지 정책은 아직 확정하지 않는다.

## Phase 0: 프로젝트 지침과 문서

**상태: 완료**

- 프로젝트 목표, MVP 범위, 사용자 흐름, 데이터 운영 원칙을 문서화한다.
- 빈 `raw`, `working`, `reviewed` 작업 공간을 만든다.
- Phase 0 완료 시점에는 기술 스택과 기준 데이터 형식을 미결정으로 남겼다. 이후 MVP 구현 기준은 Phase 1 준비 문서에서 결정한다.

**완료 기준:** 문서 간 용어와 상태가 일치하고 코드·패키지 없이 다음 데이터 작업을 시작할 수 있다.

## Phase 1: 강의 분석 자료와 예상 문제 Excel 적재 및 검수

**상태: 진행 중**

- 사용자가 제공한 원본과 출처 메타데이터를 보관한다.
- 일부 자료로 문제 추출, 중복 확인, 중국어 정리, 병음·한국어 추가, 유형·출처 검수 흐름을 실행한다.
- 답변 없는 예상 문제를 정상 상태로 유지한다.

현재 진행 상태:

- 첫 원본 Excel 적재와 읽기 전용 구조 조사 완료
- Part 1~7과 시각 자료 대표 표본 검증 완료
- 구현 기술 독립적인 데이터 스키마 v1과 강의 근거용 additive v1.1 문서화 완료
- TSC 1~7강 분석 Markdown의 근거 종류·충돌을 보존한 `course-import-v1` working 구조화 완료
- 전체 workbook의 Question·AnswerPoint 253개와 시각 자료 메타데이터를 `full-import-v1` working으로 구조 반입 완료
- Part 2 출처 추천 답변 48개와 Part 7 StoryGuide 12개 반입 완료
- 강의 데이터와 Question의 엄격한 연결·사용 후보 및 사람 검수 큐 생성 완료
- Level 8 목표 대비 데이터 공백 분석과 고득점 데이터 보강 계획 완료
- 모바일 UI 명세, 화면 데이터 계약과 화면 이동 흐름 문서화 완료
- React + TypeScript + Vite, reviewed JSON과 개인 IndexedDB의 MVP 구현 기준 결정 완료
- Part 4 첫 수직 기능 구현 계획 완료
- React + TypeScript + Vite 프로젝트 초기화 완료
- Part 4 raw 표본 6개 fixture를 보존하고, 전체 working 50문제 앱 fixture와 런타임 검증 완료
- Part 4 전체 목록·검색·필터·랜덤 문제와 텍스트 문제 흐름 완료
- IndexedDB v2 `PracticeDraft` 저장·수정·삭제와 기존 개인 데이터 보존 migration 완료
- Part 4 50문제 복습, 마지막 문제 이어서 보기와 공통 강의 자료 표시 완료
- deterministic mock 교정과 승인 후 IndexedDB `UserAnswer` 저장 완료
- 사용자 선택 기반 `ReviewState`와 개인 `Correction` 최소 흐름 완료
- 타입 검사, lint, 단위·컴포넌트 테스트와 production build 기준 마련 완료
- Part 4 50문제의 deterministic 검수 fixture와 로컬 필드별 검수 화면 완료
- 검수 결정 JSON 내보내기·가져오기, stale 판정과 reviewed 승격 CLI 완료
- 검수 결정·학습 개인 데이터·공용 working 데이터의 저장 경계 분리 완료
- Part 4 질문 이해→키워드 설계→구조별 작성→암기·회상 흐름과 IndexedDB v3 개인 이력 완료
- 실제 Part 4 사람 검수, 결정 파일 Git 반영과 reviewed 데이터 생성 미완료
- reviewed 부분 데이터의 학습 앱 연결 미완료
- 전체 253개 문제의 중국어·병음·한국어·출처 사람 검수와 `reviewed` 승격 미완료
- 시각 자료 권리, 미연결 VisualQuestion과 Part 7 후보 관계 승인 미완료
- `full-import-v1` 전체 253문제의 앱 런타임 연결 미완료. 현재는 Part 4 50문제만 별도 working fixture로 연결
- 실제 AI 연결, 개인 데이터 서버 동기화, 전체 Part 구현과 배포 미완료
- 새 모범답안 작성, 공용 실수 노트 전체와 Part 1·2·3·5·6·7 구현 미완료

Part 4 수직 기능은 Phase 2~4의 핵심 경계를 raw 표본으로 조기에 검증한 것이며, 검수된 전체 데이터나 각 Phase 완료를 뜻하지 않는다. Phase 1 전체는 계속 진행 중이다.

**완료 기준:** 대표 표본이 원본 위치까지 추적 가능하며 `raw` → `normalized` → `verified` 흐름을 통과한다.

## Phase 2: 파트별 학습과 문제 조회 MVP

- Part 1~7 가이드와 검수된 문제를 조회한다.
- 문제·표현·답변의 중국어, 병음, 한국어 뜻을 함께 표시한다.
- 답변이 없는 문제를 오류 없이 다룬다.

**완료 기준:** 검수된 표본 데이터로 파트 학습과 문제 조회 흐름을 사용할 수 있다.

## Phase 3: 한국어·중국어 답변 교정 기능

- 한국어, 중국어, 혼합 입력을 처리한다.
- 사용자 의미와 표현을 유지하는 최소 교정을 기본으로 한다.
- 세 언어 결과, 수정 전후, 이유, 답변 구조를 제공한다.

**완료 기준:** 정해진 검수 예시에서 개인 경험을 만들지 않고 일관된 결과 형식을 반환한다.

## Phase 4: 나의 답변 저장, 문제 복습, 실수 노트

- 사용자가 승인한 답변을 개인 데이터로 저장한다.
- 개인 `ReviewState`의 `못 외움`, `헷갈림`, `외움` 상태로 문제와 오류를 복습한다.
- 강의 대표 오류와 개인 오류를 구분한다.

**완료 기준:** 공용 콘텐츠와 개인 기록이 분리된 상태로 네 가지 핵심 메뉴의 학습 순환이 이어진다.

## Phase 5: 표시 제어와 복습 개선

- 병음·한국어 뜻 숨기기
- 랜덤 복습
- `못 외움`과 `헷갈림` 등 약점 우선 복습

**완료 기준:** 사용자가 회상 난이도와 복습 대상을 조절할 수 있다.

## Phase 6: 답변 표현 모드

- 최소 교정
- 쉽게 말하기
- 자연스럽게
- Level 8 확장

각 모드는 명확히 구분하고 사용자의 의미와 경험을 유지한다.

**완료 기준:** 같은 입력의 모드별 결과가 구분되고 기본값은 계속 최소 교정이다.

## Phase 7: 선택 기능

- 로그인
- 개인 데이터 동기화
- 배포 환경 구성
- 운영에 필요한 선택 기능

**완료 기준:** 필요성과 데이터 보호 방식을 먼저 결정한 기능만 도입한다.

## 현재 우선순위에서 제외

녹음, 음성 인식, 음성 평가, 질문 음성 재생은 현재 MVP와 로드맵의 우선 기능에서 제외한다. 필요성이 새로 확인되면 별도 의사결정으로 검토한다.
