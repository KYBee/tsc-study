# AI 답변 교정 규칙

## 목적

사용자가 한국어, 중국어 또는 두 언어를 섞어 입력한 내용을 질문에 맞는 자연스러운 중국어 답변으로 정리한다. 기본 목표는 고급 표현 추가가 아니라 의미를 보존하면서 문법, 어순, 단어 선택, 내용 연결의 실수를 줄이는 것이다.

## 핵심 원칙

1. **원래 의미 유지:** 주장, 선호, 이유, 경험, 시간, 장소 등 사용자가 말한 사실을 바꾸지 않는다.
2. **원래 표현 재사용:** 사용자가 쓴 중국어 단어와 문장 구조를 가능한 한 유지한다.
3. **최소 수정 우선:** 틀리거나 매우 부자연스럽거나 의미 전달을 방해하는 부분부터 고친다.
4. **문법과 어순 교정:** 문법, 어순, 단어 선택, 호응, 연결 관계를 확인한다.
5. **질문 관련성 확인:** 답변이 질문에 직접 답하는지 확인한다. 관련 없는 부분은 삭제 여부를 임의 결정하지 말고 이유와 수정안을 제시한다.
6. **직역 교정:** 한국어식 또는 다른 언어식 직역으로 매우 부자연스러운 표현만 자연스러운 중국어로 바꾼다.
7. **개인 경험 생성 금지:** 사용자가 말하지 않은 직업, 가족, 장소, 사건, 감정, 수치 등 개인 정보를 만들지 않는다.
8. **교정과 확장 분리:** 기본 최소 교정과 “Level 8답게 확장”을 하나의 결과에 섞지 않는다.
9. **세 언어 정보 반환:** 교정 중국어, 전체 병음, 한국어 뜻을 함께 반환한다.
10. **변경 근거 공개:** 수정 전 표현, 수정 후 표현, 간단한 이유를 반환한다.
11. **불확실성 표시:** 질문의 Part, 원문의 의미, 고유명사, 출처 규칙 등을 확신할 수 없으면 임의로 단정하지 않는다.

## 입력 유형별 처리

### 한국어 입력

- 사용자가 말한 의미 단위를 먼저 구분한다.
- 내용을 자연스러운 중국어로 옮기고, Part가 확인되어 있으면 해당 답변 구조 순서로 정리한다.
- 중국어에 없는 개인 정보나 구체적인 경험을 보충하지 않는다.
- 여러 번역이 가능하거나 원문의 지시 대상이 모호하면 하나를 사실처럼 정하지 않고 확인 필요 사항을 알린다.
- 쉬운 표현으로 충분하면 불필요한 고급 어휘를 추가하지 않는다.

### 중국어 입력

- 문법, 어순, 단어 선택, 내용 연결이 틀릴 수 있다고 가정하고 검토한다.
- 먼저 질문에 직접 답한 부분과 사용자의 핵심 의미를 식별한다.
- 사용자가 쓴 단어와 문장 구조를 최대한 재사용한다.
- 올바르고 자연스러운 구간은 바꾸지 않는다.
- 오류 또는 매우 부자연스러운 부분만 수정하고 각 변경 이유를 짧게 설명한다.
- 사용자의 의미나 개인 경험이 바뀌는 수정은 하지 않는다.

### 한국어·중국어 혼합 입력

- 두 언어에 담긴 의미를 하나의 의미 목록으로 합친다.
- 이미 자연스러운 중국어는 유지한다.
- 한국어 구간만 문맥에 맞는 중국어로 옮기고 전체 연결을 최소한으로 조정한다.
- 두 언어의 내용이 충돌하면 임의로 하나를 선택하지 말고 확인이 필요하다고 표시한다.

## 교정 절차

1. 질문의 중국어, 병음, 한국어 뜻과 확인된 Part를 읽는다.
2. 사용자의 입력에서 주장, 이유, 예시, 경험, 결론을 추출하되 새 내용을 만들지 않는다.
3. 질문에 직접 답했는지와 주제에서 벗어난 내용이 있는지 확인한다.
4. 중국어 원문의 유지 가능한 표현을 표시한다.
5. 문법, 어순, 단어 선택, 연결, 부자연스러운 직역을 최소 범위로 수정한다.
6. Part가 확인된 경우 수정된 문장을 권장 구조 단계에 연결한다. 구조를 맞추기 위해 사실을 새로 추가하지 않는다.
7. 전체 병음과 한국어 뜻이 교정 중국어 전체에 대응하는지 확인한다.
8. 수정 전후와 이유를 작성한다.
9. 모호하거나 근거가 부족한 내용은 확인 필요로 반환한다.

## 기본 결과 형식

| 항목 | 내용 |
|---|---|
| `corrected_zh` | 최소 교정된 전체 중국어 |
| `pinyin` | `corrected_zh` 전체에 대응하는 성조 포함 병음 |
| `ko` | 의미와 뉘앙스를 유지한 전체 한국어 뜻 |
| `changes` | 수정 전 표현, 수정 후 표현, 간단한 수정 이유의 목록 |
| `structure_segments` | 확인된 Part 구조 단계와 해당 문장 구간 |
| `relevance_note` | 질문과 관련 없는 내용 또는 질문에 빠진 직접 답변에 대한 설명 |
| `uncertainties` | 임의로 확정하지 않은 모호한 내용 |
| `save_candidate` | 사용자가 검토한 뒤 나의 답변으로 저장할 수 있는 세 언어 결과 |

수정할 부분이 없으면 변경을 억지로 만들지 않고 `changes`에 “수정 없음”을 기록한다.

## 최소 교정과 Level 8 확장

| 구분 | 기본 최소 교정 | Level 8답게 확장 |
|---|---|---|
| 실행 조건 | 기본 동작 | 사용자가 명시적으로 선택한 경우만 |
| 목적 | 오류 제거와 자연스러운 연결 | 정확한 기본 답변을 바탕으로 내용·표현 확장 |
| 어휘 | 원래 어휘 최대한 유지 | 필요할 때 선택지를 제안하되 의미를 바꾸지 않음 |
| 경험 | 새로 만들지 않음 | 새로 만들지 않음 |
| 결과 | 사용자의 답변을 교정 | 기본 결과와 분리된 별도 결과 |

Level 8 확장은 현재 구현 우선순위가 아니다. 확인되지 않은 채점 기준을 근거로 표현을 추가하지 않는다.

## 교정 예시

### 문제

**中文**

你喜欢在哪儿运动？

**Pinyin**

Nǐ xǐhuan zài nǎr yùndòng?

**한국어**

당신은 어디에서 운동하는 것을 좋아하나요?

### 사용자 중국어

**中文**

我喜欢在家运动。工作很忙，没有时间去健身房。在家看视频运动很方便。

**Pinyin**

Wǒ xǐhuan zài jiā yùndòng. Gōngzuò hěn máng, méiyǒu shíjiān qù jiànshēnfáng. Zài jiā kàn shìpín yùndòng hěn fāngbiàn.

**한국어**

저는 집에서 운동하는 것을 좋아합니다. 일이 매우 바빠서 헬스장에 갈 시간이 없습니다. 집에서 영상을 보며 운동하면 매우 편리합니다.

### 최소 교정

**中文**

我喜欢在家运动。因为工作很忙，我没有时间去健身房。在家一边看视频一边运动很方便。

**Pinyin**

Wǒ xǐhuan zài jiā yùndòng. Yīnwèi gōngzuò hěn máng, wǒ méiyǒu shíjiān qù jiànshēnfáng. Zài jiā yìbiān kàn shìpín yìbiān yùndòng hěn fāngbiàn.

**한국어**

저는 집에서 운동하는 것을 좋아합니다. 일이 매우 바빠서 저는 헬스장에 갈 시간이 없습니다. 집에서 영상을 보면서 운동하는 것은 매우 편리합니다.

### 변경 설명

| 수정 전 | 수정 후 | 이유 |
|---|---|---|
| `工作很忙，没有时间去健身房。` | `因为工作很忙，我没有时间去健身房。` | 바쁜 것이 헬스장에 갈 시간이 없는 이유임을 명확히 연결하고 주어를 보완했다. |
| `在家看视频运动很方便。` | `在家一边看视频一边运动很方便。` | 동시에 이루어지는 두 행동의 관계를 자연스럽게 표현했다. |

첫 문장과 `工作很忙`, `没有时间去健身房`, `在家`, `看视频`, `运动很方便` 등 사용자의 핵심 단어와 경험은 그대로 유지했다. 더 어려운 어휘나 새로운 개인 경험은 추가하지 않았다.

## 금지되는 처리

- 답변을 더 인상적으로 보이게 하려고 사용자의 경험을 바꾸거나 새로 만들기
- 올바른 쉬운 표현을 이유 없이 어려운 유의어로 교체하기
- 최소 교정 결과에 Level 8 확장을 자동으로 섞기
- 질문 또는 Part가 확인되지 않았는데 시험 규칙을 단정하기
- 병음이나 한국어 뜻이 일부 문장만 반영된 상태로 검수 완료 처리하기
- 확신할 수 없는 고유명사, 수치, 출처를 추측해 채우기

## 앱의 실제 교정 endpoint 계약

- 앱은 `VITE_TSC_CORRECTION_API_URL`이 설정된 경우에만 same-origin 경로 또는
  HTTPS endpoint로 기존 `CorrectionRequest` JSON을 전송한다.
- 한국어 입력은 의미와 개인 경험을 보존한 말하기 쉬운 중국어·전체 병음·한국어
  의미·핵심 표현을, 중국어 입력은 최소 교정·전체 병음·한국어 뜻·변경 이유를,
  혼합 입력은 의도를 보존한 구어체 정리를 반환해야 한다.
- 응답은 `CorrectionProviderResult` discriminated union과 Zod 계약을 통과해야
  하며 원문의 `original_input`이 요청과 다르면 거부한다.
- HTTP 오류, timeout, 잘못된 JSON과 schema 불일치는 원문을 포함한 `failure`로
  바꾸며 PracticeDraft를 삭제하지 않는다.
- `VITE_*` 환경변수는 browser bundle에 공개되므로 API key나 provider secret을
  저장하지 않는다. 인증은 endpoint의 same-origin session 또는 서버 측 설정이
  담당한다.
- endpoint 미설정 상태에서는 기존 P4-006 deterministic mock만 동작한다.
