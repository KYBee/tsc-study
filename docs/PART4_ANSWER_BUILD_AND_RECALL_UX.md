# Part 4 답변 만들기와 회상 UX

## 목적

Part 4의 검수 전 working 50문제를 빈 입력창에서 바로 답하는 방식뿐 아니라 질문 이해, 답변 설계, 구조별 작성, 답변 확인, 암기·회상 순서로 학습할 수 있게 한다. 앱은 사용자가 직접 입력한 내용만 저장하며 중국어·병음·한국어를 생성하거나 수정하지 않는다.

## 학습 흐름

```text
질문 이해
→ 답변 설계
→ 답변 작성
→ 내가 작성한 연습 답변 확인
→ 암기 연습
→ 회상 결과 선택
→ ReviewState 저장
```

1. 질문 이해에서는 중국어, 병음, 한국어, 유형, 원본 AnswerPoint와 실제 데이터에 있는 시간 정보만 확인한다.
2. 답변 설계에서는 `직접 답변`, `이유`, `경험 또는 예시`, `마무리`의 네 칸에 사용자가 키워드를 직접 쓴다. 각 칸은 생략할 수 있다.
3. 답변 작성은 구조별 작성이 기본이며 기존 자유 입력인 전체 답변 작성도 유지한다. 네 구간 미리보기는 비어 있지 않은 사용자 입력을 순서대로 줄바꿈해 합칠 뿐 연결어를 생성하지 않는다.
4. 사용자가 `답변 작성 완료`를 명시적으로 누르면 완료 상태가 된다. 모든 구간을 채웠는지는 완료 조건이 아니다.

## 개인 데이터

`PracticeDraft`에는 기존 `original_input`과 함께 다음 선택 필드를 추가한다.

- `planning_keywords`: 네 구조별 사용자 키워드
- `structured_answer`: 네 구조별 사용자 문장
- `full_text`: 사용자가 작성한 전체 답변
- `completion_status`: `in_progress` 또는 `completed`
- `completed_at`
- `understanding_confirmed`
- `skipped_sections`

기존 v2 자유 입력 초안에는 이 필드가 없어도 정상이다. 이 경우 `original_input`을 전체 답변으로 표시한다.

`ReusablePhrase`는 사용자가 명시적으로 누른 원문 전체만 저장하는 개인 데이터다. 자동 번역·요약·문장 분해를 하지 않으며 공용 `LearningExpression`과 구분한다.

`RecallAttempt`는 암기 모드, 사용자가 선택한 결과와 시각을 기록한다. 연습 초안 또는 교정 완료 답변을 참조하며 다음 복습 날짜는 만들지 않는다.

## 암기 모드와 상태 매핑

- 전체 보기: 저장 답변과 질문 언어·키워드를 함께 확인
- 중국어만 보기: 저장된 답변의 중국어 원문만 확인
- 키워드만 보기: 네 구조의 키워드만 확인
- 질문만 보기: 답변을 숨기고 말한 뒤 명시적으로 공개

회상 결과는 다음과 같이 기존 `ReviewState`에 매핑한다.

| 회상 결과 | ReviewState |
|---|---|
| 못 말함 | 못 외움 |
| 키워드 보고 말함 | 헷갈림 |
| 거의 말함 | 헷갈림 |
| 외워서 말함 | 외움 |

상세 결과는 `RecallAttempt`에 남고 `ReviewState`는 기존 세 단계 상태만 관리한다.

## IndexedDB migration

학습 DB 이름 `tsc-study-part4-fixture-v1`을 유지하면서 버전을 v3로 올린다. 기존 네 store와 레코드를 변경하지 않고 `reusablePhrases`, `recallAttempts`를 추가한다. 검수 DB `tsc-study-data-review-v1`에는 영향을 주지 않는다.

## 실제 AI가 없는 제한

한국어 입력은 구조와 내용만 저장한다. 중국어 변환, 중국어 교정, 병음 생성은 하지 않는다. 기존 P4-006의 정확한 계약 입력만 deterministic mock 성공을 지원하며 그 밖의 입력은 계속 `unsupported_by_mock`이다. 연습 초안은 mock 지원 여부와 관계없이 저장할 수 있지만 `UserAnswer`나 `Correction`으로 자동 승격되지 않는다. `ModelAnswer`는 계속 0개다.
